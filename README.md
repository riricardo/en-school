# English Quest

Flashcards estáticos com a interface simples do Japcket. HTML, CSS e JavaScript com Vite, sem React.

Instalação e publicação: [SUBSTITUIR.md](SUBSTITUIR.md).
Fluxo e regras: [METODOLOGIA.md](METODOLOGIA.md).
Contrato do conteúdo: [DADOS.md](DADOS.md).
Verificações e limitações: [VERIFICACAO.md](VERIFICACAO.md).

Este pacote completo inclui `data.js` com 30 itens de teste. Use Node.js 22.12 ou mais recente, execute `npm install` e depois `npm run dev`. Se estiver atualizando um projeto com conteúdo próprio, preserve seu `data.js`.
